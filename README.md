# Data Structures and Graph Algorithms

This is the Java code I wrote in 2020. Some of it is practice from when I was learning to program, and the rest is from 2 courses of my B.Sc. in Computer Science and Engineering at BRAC University.

## What is inside

| Folder | What it does |
|---|---|
| `01-java-practice` | Practice programs from summer 2020: loops, number problems (prime, Fibonacci, palindrome and Armstrong numbers), arrays and matrices, star patterns, simple classes and my first linked lists |
| `02-data-structures` | Labs from CSE220 Data Structures: linear and circular arrays, linked lists, a dummy headed doubly circular linked list, stacks, queues (with a hospital waiting room example), recursion, searching and sorting |
| `03-algorithms` | Labs from CSE221 Algorithms: graph traversal (BFS), shortest path (Dijkstra) and dynamic programming (longest common subsequence) |

`02-data-structures/01-linear-array` started from a template in the course lab sheet, and I wrote the method bodies.

## How to run

Step 1: Install Java 8 or newer.

Step 2: Go to a folder and run `javac *.java`.

Step 3: Run `java <ClassWithMain>`.

Some programs read the input from a text file with a fixed Windows path. Change the path first if needed.
